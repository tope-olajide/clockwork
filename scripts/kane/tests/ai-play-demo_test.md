# Neon Runner AI Play

Saved so every attempt after the first replays recordings instead of paying the
authoring cost again. Run it with `--url` pointing at the snapshot player.

## Wait for the AI Play HUD

Wait until the "AI PLAY" state panel shows STATUS, COINS and LAST ERROR.

## Move right through the level

Click "MOVE RIGHT" once, wait 3 seconds, then verify the STATUS value reads "WON", the COINS value reads "3", and LAST ERROR reads "none".

# Archive: planning documents

These are the planning and design documents written while Clockwork was being
built. They describe intended work and the state of the project on the day
each was written, so their "to do", "not yet run" and "missing" notes are
historical. They are kept so the design reasoning stays traceable.

For the current state of the project, read:

- [`README.md`](../../README.md): what Clockwork is and how to run it.
- [`docs/kane-proof.md`](../kane-proof.md): every Kane CLI run and what it proved.
- [`docs/FEATURE_VERIFICATION.md`](../FEATURE_VERIFICATION.md): each feature mapped to its code and proof.
- [`docs/known-issues.md`](../known-issues.md): current scope and limitations.

| File | What it was |
|---|---|
| `KANE_AI_TESTING_IMPLEMENTATION_PLAN.md` | Design and phase plan for AI Testing and Test Mode. |
| `chat-kane-integration-plan.md` | Proposal for connecting the chat agent to Kane, since implemented (`verify_with_kane`). |
| `agent-chat-ux-plan.md` | Design notes for the agent chat drawer. |
| `game-starter-templates-plan.md` | Plan for the genre starter templates. |
| `slice-3-7-fixes.md` | Remediation checklist written after an audit of Slices 3–7; its items were completed afterwards (see `docs/implementation-log.md`). |
| `video-scene/` | Storyboard for an earlier demo video, captured with fixture Kane and a mock planner. |

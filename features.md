# Clockwork Features

Only features that are **100% implemented, manually verified, and passing the current slice gate** are listed here. Planned, partial, mocked, or disabled work does not belong in this file. Put limitations and unfinished work in [`docs/known-issues.md`](docs/known-issues.md).

## Status

The Slice 0 static shell is implemented and verified at 1024×768, 1366×768, 1440×900, 1601×900, and 1920×1080. No product feature is complete yet: the project data, canvas, and command palette actions are static placeholders, and engine work begins in Slice 1.
